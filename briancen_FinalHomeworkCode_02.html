Favorite Titi Monkey

Prompt: Every Saturday morning, at the same time, a primatologist goes and sits in the forest to listen for titi monkey calls, counting the number of calls they hear in a 2 hour window from 5am to 7am. Based on previous knowledge, she believes that the mean number of calls she will hear in that time is exactly 15. Let X represent the appropriate Poisson random variable of the number of calls heard in each monitoring session.

Challenge 1: What is the probability that she will hear more than 8 calls in a session?

p_more_than_8 <- ppois(8, lambda = 15, lower.tail = FALSE)

Challenge 2: What is the probability that she will hear no calls in a session?

p_0_calls <- dpois(0, lambda = 15)

Challenge 3: What is the probability that she will hear exactly 3 calls in a session?

p_is_3 <- dpois(3, lambda = 15)

Challenge 4: Plot the relevant Poisson mass function over the values in range 0 ≤ 𝑥 ≤ 30.

x <- 0:30
l = 15
probset <- dpois(x = x, lambda = l)
barplot(probset, names.arg = x, space = 0, xlab = "x", ylab = "Pr(X = x)", main = "Probability Mass Function")

## Challenge 5:Simulate 104 results from this distribution (i.e., 2 years of Saturday monitoring sessions).

simulation <- rpois(104, lambda = 15)

Challenge 6:Plot the simulated results using hist() and use xlim() to set the horizontal limits to be from 0 to 30. How does your histogram compare to the shape of the probability mass function you plotted above?

hist(simulation, xlim = c(0, 30))

#Response to question: The histogram of the simulated results looks very similar to the theoretical Poisson probability mass function. Both plots show that the distribution is unimodal with the highest frequency around 15 calls and tapering off on both sides. Although the simulation (with 104 sessions) shows some random fluctuations because of the limited sample size, its overall shape confirms the expected Poisson pattern. With a larger number of simulations, the histogram would converge even more closely to the PMF
